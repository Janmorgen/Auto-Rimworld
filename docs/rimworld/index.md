# RimWorld Core Mechanics — Reference Index

*Base game only — none of these files include content from Royalty, Ideology, Biotech, Anomaly, or Odyssey.*

A linked set of reference files covering RimWorld's core (vanilla) systems, each pair split into a "system" file and a "catalog/deep-dive" file where that split makes sense. Every file links back here and to a few related files.
